# BIPS v3 — Чеклист тестирования перед продажей

**Версия прошивки:** v4.0.7+
**Дата:** 2026-08-07

---

## 1. Прошивка (USB)

- [ ] Подключить устройство по USB
- [ ] Прошить через ESP Flash Download Tool (v4.0.7+)
- [ ] Убедиться, что **НЕ** включать `blank_nvs.bin`
- [ ] Перезагрузить устройство

---

## 2. Дисплей

- [ ] Экран включается при загрузке
- [ ] Текст отображается **правильно ориентирован** (не вверх ногами, не зеркально)
- [ ] Белый текст на чёрном фоне
- [ ] Нет мёртвых пикселей / артефактов
- [ ] Часы отображаются корректно (после синхронизации NTP)
- [ ] Экран гаснет через 60 секунд бездействия
- [ ] Экран загорается при нажатии кнопки

---

## 3. Кнопка (TTP223, GPIO43)

- [ ] Одиночное нажатие — включает/выключает ассистента
- [ ] Двойное нажатие — не вызывает ложных срабатываний
- [ ] Удержание 3 сек — перезагрузка устройства
- [ ] Дебаунс работает (нет самопроизвольных срабатываний)
- [ ] Кнопка отзывчивая (задержка < 500мс)

---

## 4. Аудио

- [ ] Динамик работает (слышно приветствие при загрузке)
- [ ] Громкость адекватная (не слишком тихо/громко)
- [ ] Кнопки VOL+/VOL- работают
- [ ] Микрофон распознаёт голос (проверить через "Привет")
- [ ] Нет искажений / шума / эха

---

## 5. WiFi

- [ ] Подключение к WiFi работает (двойной клик BOOT → AP режим)
- [ ] Веб-интерфейс открывается (192.168.4.1)
- [ ] Можно ввести пароль WiFi
- [ ] После перезагрузки WiFi подключается автоматически
- [ ] При смене сети — можно переподключить

---

## 6. Облачный сервис (Xiaozhi)

- [ ] Устройство подключается к облаку (лог "Connected to MQTT")
- [ ] Голосовой ассистент отвечает на вопросы
- [ ] Русский язык работает
- [ ] Распознавание речи точное (проверить 3-5 фраз)
- [ ] TTS (озвучка) работает без задержек

---

## 7. OTA (обновление по воздуху)

- [ ] При перезагрузке проверяет обновления
- [ ] Если есть новая версия — скачивает и устанавливает
- [ ] После обновления — устройство перезагружается с новой версией
- [ ] Версия прошивки отображается в логах (USB Serial JTAG)

---

## 8. Энергосбережение

- [ ] Экран гаснет через 60 секунд
- [ ] Устройство не перезагружается самопроизвольно
- [ ] Батарея держит заряд (минимум 2-3 часа активного использования)
- [ ] Зарядка работает (USB-C)

---

## 9. Физическое состояние

- [ ] Корпус целый, без трещин / сколов
- [ ] Все компоненты надёжно закреплены
- [ ] Провода аккуратно уложены
- [ ] Батарея не болтается
- [ ] Кнопка не заедает
- [ ] Разъём USB-C работает

---

## 10. Финальная проверка

- [ ] Устройство включается с первого раза
- [ ] Приветственное сообщение проигрывается
- [ ] Часы показывают правильное время
- [ ] Можно провести диалог (3+ реплики)
- [ ] Устройство засыпает и просыпается корректно

---

## Тест-сценарий (5 минут)

1. **Включить устройство** → должно проиграть приветствие
2. **Подождать 10 сек** → часы должны показать время
3. **Нажать кнопку** → ассистент должен сказать "Слушаю"
4. **Сказать "Привет"** → должен ответить
5. **Сказать "Какая погода в Москве?"** → должен ответить
6. **Подождать 60 сек** → экран должен погаснуть
7. **Нажать кнопку** → экран загорается, ассистент активен
8. **Удержать кнопку 3 сек** → устройство перезагружается

---

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| Экран вверх ногами | Проверить версию прошивки (должна быть v4.0.6+) |
| Кнопка сама срабатывает | Проверить версию прошивки (должна быть v4.0.7+) |
| WiFi не подключается | Двойной клик BOOT → AP режим → 192.168.4.1 |
| Ассистент не отвечает | Проверить WiFi подключение и MQTT в логах |
| OTA не работает | Проверить интернет-соединение |
| Экран не гаснет | Проверить версию прошивки (должна быть v4.0.5+) |
